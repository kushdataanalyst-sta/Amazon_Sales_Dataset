# Amazon_Sales_Dataset
Project Overview

This Data Analyst portfolio project uses Python to analyze Amazon Sales Dataset and explore product pricing, discounts, customer ratings, review counts, and category-level trends.

Objectives

Analyze actual and discounted product prices.

Explore discount patterns across products.

Compare average ratings across product categories.

Examine review counts and customer engagement.

Identify missing values, duplicate records, and data quality issues.

Create visualizations to communicate key findings.

Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Google Colab

Skills Demonstrated

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Statistical analysis

Data visualization

Category-wise analysis

Insight generation

Dataset

The notebook expects a CSV file named amazon.csv. Upload the dataset to Google Colab before running the analysis.

Important Note

This project analyzes product listings, not confirmed sales transactions. Review counts and listing prices should not be interpreted as actual sales volume or revenue.
